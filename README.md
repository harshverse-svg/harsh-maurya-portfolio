## 🏛️ Philosophy & Design Architecture

A developer portfolio built on an **"Architecture First"** aesthetic—combining Scandinavian dark-mode minimalism, Bento Grid modularity, procedural 3D graphics, and lightweight CSS glassmorphism.

### Key Architectural Pillars
- **Procedural 3D GPU Unfolding Intro**: 100% procedural Three.js graphics card (backplate, bracket, PCB, compute die, 6x VRAM packages, 72-fin aluminum heatsink, 4x copper heatpipes, triple-fan cooling array, PCIe gold contacts) with choreographed GSAP mechanical unfolding, dynamic SVG leader lines, and reverse fold-back on entry.
- **Spark 3D Companion Pet**: Interactive procedural floating 3D companion with idle hovering, click pulse reactions, and conversational AI guidance.
- **Bento Box Technical Stack**: Information-dense, modular grid highlighting languages, AI prototyping tools, and cloud environments.
- **Glassmorphism Research Lab**: Dedicated translucent UI container spotlighting emerging AI and software architecture experiments.
- **System Architecture Visualizations**: Custom CSS-rendered directional flowcharts illustrating end-to-end data pipelines for flagship projects.
- **Precision Micro-Interactions**: Physics-based custom cursor with trailing follower, smooth scroll progress indicator, and IntersectionObserver-driven scroll reveals.
- **Zero-Toolchain Deployment**: Engineered completely with pure semantic HTML5, modern CSS3 custom properties, Three.js ESM via importmaps, and vanilla ES6+ JavaScript—achieving near-instant First Contentful Paint (FCP) and zero bundle overhead.

## 🛠️ Quick Start & Local Development

No package managers, build steps, or compilers required.

### 1. Clone the repository
```bash
git clone https://github.com/harshverse-svg/harsh-maurya-portfolio.git
cd harsh-maurya-portfolio
```

### 2. Launch locally
Open `index.html` directly in any modern browser, or run a lightweight local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
