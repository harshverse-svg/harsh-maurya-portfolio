# Harsh Maurya | Digital Architect

Professional personal portfolio website designed with a dark, high-end "Architecture First" aesthetic.

## Features
- **Bento Box UI**: Clean presentation of Core Technical Stack.
- **Glassmorphism Lab**: Specialized section for emerging tech and AI research.
- **Architecture Flow Diagrams**: CSS-based system design visualizations for flagship projects.
- **Micro-Interactions**: Custom glowing cursor, 2% scale hovers, and intersection observer animations.

## Setup
Just open `index.html` in your browser. No build steps required.

## Structure
- `/css`: Stylesheets (Main & Animations)
- `/js`: Logic (Cursor & Scroll events)
- `/assets`: Media, SVGs, and Resume
